# MacRemote 1.1.1

MacRemote 1.1.1 finds command-line tools installed with npm and other JavaScript package managers, including Wrangler. Your tools, settings, and connected apps carry over from 1.1.

## Download

Download `MacRemote-1.1.1-macos-universal2.zip` from [GitHub Releases](https://github.com/viticci/MacRemote/releases). Unzip it, move **MacRemote** to Applications, and open it. The release also lists a `.sha256` checksum for the ZIP. MacRemote is signed with a Developer ID and notarized by Apple.

## Fixed

- **"Wrangler isn't installed on this Mac" when it was** ([#11](https://github.com/viticci/MacRemote/issues/11)). An app opened from Finder doesn't get the `PATH` your shell sets up, and MacRemote didn't look in the folders where npm, Volta, pnpm, and Yarn put global commands. It now also looks in `~/.npm-global/bin`, `~/.volta/bin`, `~/Library/pnpm`, `~/.yarn/bin`, and the `bin` folder of the `prefix` set in `~/.npmrc`. This helps everywhere MacRemote finds a tool: setting up your own domain, presets, the tool scan, and the `PATH` your tools run with. If MacRemote still can't find Wrangler, the message now says so, rather than saying it isn't installed. Thanks to Paul Robichaux for the report and for a pull request that pointed the way.
