# MacRemote 1.0

MacRemote lets ChatGPT, Claude, and other AI apps use the tools you choose on
your Mac. This is a fresh 1.0 for MacStories Club members: everything from the
earlier betas, plus the security work since then, in one build that is signed
and notarized.

## Download

Download `MacRemote-1.0.zip` from the Club post. It unpacks to a **MacRemote
1.0** folder with the app, the Club guide, these notes, and the source code.

MacRemote 1.0 needs macOS 26 or later and runs on Apple silicon and Intel Macs.
It is signed with a Developer ID and notarized by Apple, so it opens with a
double-click. You no longer need **Open Anyway**. The
[Club Beta Guide](../CLUB_BETA.md) walks you through the first run.

## What's in 1.0

- **Share only what you choose.** Command-line tools, single workflows from
  them, bundles from the Library, and tools from MCP servers already set up on
  your Mac. Nothing is visible to an app until you turn on **Share**.
- **Approve every app.** A new app's sign-in page and MacRemote both show a
  six-digit code. Approve only when they match.
- **Tools that change something ask first,** and show every argument in full
  before they run. **Always Allow** works per app and per tool.
- **File Transfer** can list, find, read, write, and download files in the
  folders you allow, or the whole Mac if you choose. Protected locations, like
  SSH keys and cloud credentials, are never reachable.
- **Instant Link** gives you a temporary public address with no account.
  **Your Domain** gives you a stable one on a domain you own through
  Cloudflare, and comes back with **Go Public** after a restart.
- **Formatted results** in apps that support MCP Apps, with clean text and
  structured data for the rest.
- **Works with Claude's and ChatGPT's current connector forms.** In Claude,
  both **Use Claude's published identity** and **Register automatically** sign
  in. For ChatGPT, which shows an icon only if you upload a small one, your
  link serves one that fits at `/macremote-icon-256.png`.
- **A refused sign-in says so.** The browser shows a short explanation and
  **Activity** records the reason.
- **A new icon,** built for Liquid Glass.

## If you tested an earlier beta

Quit the old MacRemote and replace it in Applications. Your tools, connected
apps, and settings carry over.

The earlier betas were signed differently, so macOS may ask whether MacRemote
can use items it saved in your keychain. Enter your Mac password and choose
**Always Allow**.

Three things you will notice:

- **File Transfer reaches only folders you allow.** The built-in File Transfer
  tools start with Desktop, Documents, and Downloads. Add or remove folders in
  **Settings → Security → File Transfer Folders**, or choose **Allow Whole
  Mac…** there to let apps you trust reach every file.
- **Flexible Commands always ask first.** A Flexible Command, a tool that passes
  any arguments through to its program, now asks before every run even when it
  is labeled Read-only, unless you turned on Always Allow for that app. A
  Flexible Command you add from the Library starts Not Shared.
- **Notification banners no longer have Approve.** A banner can deny a request.
  To approve one, open MacRemote, where you can see what you are approving.

### New

- **Allow Whole Mac.** One confirmed choice in **Settings → Security → File
  Transfer Folders** lets File Transfer, and every tool that runs without
  asking, read any file your account can open. It applies to every connected
  app. Writing still asks first, and the protected locations below stay
  closed. Remove **Whole Mac** from the list to go back to your folders.
- **Find Files** (`filesystem_find`), a new File Transfer tool. It finds files
  and folders by name: exactly, inside a folder you name, or through Spotlight
  across everything File Transfer reaches. It starts Not Shared.
- **Read File returns text.** With `encoding: "utf8"` an app gets the text of a
  file instead of base64.
- **A new icon.** Your Mac, lit, at the far end of a glass tunnel. It is built
  for Liquid Glass, so it follows the Default, Dark, Clear, and Tinted icon
  styles. Connected apps and browsers show the same icon; some keep the old
  one until their own cache refreshes.
- **Your Domain goes public again without Cloudflare credentials.** After you
  deploy a domain, **Go Public** brings it back, also after a restart, with no
  API token and no Wrangler. Deploy your domain once after updating to turn
  this on. MacRemote keeps one key in your Keychain for this: the key that runs
  your deployed public link. It cannot change your DNS or create tunnels, and
  changing the domain or subdomain deletes it. Your API token is still never
  saved. The local server reuses the port your domain was deployed with; if
  another program has that port, deploy your domain again.

### Removed

- **The in-app Verify test** and its Anthropic API Key row. **Test Tool** in a
  tool's inspector is unchanged.
- **Pushover and Brrr alerts.** macOS notifications for waiting requests are
  unchanged. When your public link stops and cannot be restarted, MacRemote
  posts a macOS notification.
- **Background Tasks.** Every tool call now runs to completion inside its
  request. Over the public link, a call must finish within Cloudflare's
  100-second limit.
- **The `macremotectl` script.**
- **Seven built-in presets:** List Directory, Find By Name, Word Count, Line
  Count, Search Text File, Git Status, and Git Log. They let a connected app
  read any file, or ran programs named in a folder's Git configuration, without
  asking. Tools you already added from them stay in your list. The file tools
  among them now stay inside your File Transfer folders, and the two Git tools
  ask first.
- **The Cloudflare Access warning** during Your Domain setup.

### Security

- **Approvals show everything that will run.** A request lists every argument
  in full, including standard input, and writes out invisible characters.
- **A call is checked before you are asked.** Invalid arguments, blocked
  commands, and files outside your File Transfer folders fail without a prompt.
- **File Transfer never reaches protected locations,** even inside a folder
  you allowed or with the whole Mac allowed: SSH and GnuPG keys; AWS, Azure,
  Google Cloud, Kubernetes, Docker, Cloudflare, and GitHub CLI credentials;
  `.netrc`, `.npmrc`, `.pypirc`, and the Codex sign-in file; Keychains,
  LaunchAgents, Preferences, and MacRemote's own data.
- **Git Status and Git Log ask first.** If you added these two tools from the
  Library in 1.0, they were labeled Read-only and ran without asking. Git can
  run programs named in the settings of the folder it is pointed at, so they
  now ask before each run. Use **Always Allow** for an app you trust. You can
  change the label back in Tools.
- **The saved tools file is readable only by you.**
- **MacRemote answers only at its own addresses.** A request must name this
  Mac's local address or your public link; anything else is refused. This
  stops a web page in your browser from reaching MacRemote by pointing its own
  address at your Mac. If you forward MacRemote's port through something other
  than MacRemote's own public link, such as an SSH forward or a tunnel you
  start yourself, those requests are now refused.
- **Downloads waiting to be fetched are limited to 2 GiB in total.** Each one
  is still limited to 512 MiB, expires after 10 minutes, and can be fetched 3
  times.
- **Download Zip checks the size before it writes anything.** It refuses more
  than 512 MiB of files, and no longer copies them to a temporary folder first.
- **Signing in to an MCP server checks the sign-in service.** When a server
  names its sign-in service, MacRemote refuses metadata that describes a
  different one, and refuses an address that only looks local, such as
  `127.example.com`.
- **Cloudflare's helper is found in Homebrew and system folders first.** A
  file named `cloudflared` in a folder inside your home folder no longer runs
  instead of the copy you installed.
- **Tools that run without asking stay inside your File Transfer folders.** A
  read-only Fixed Command, such as a search or a PDF reader, can only be
  pointed at files in those folders. If one of your tools is refused, add its
  folder in **Settings → Security → File Transfer Folders**. Tools that ask
  first are not limited.
- **Sign-in shows a matching code.** A new app's request in MacRemote shows a
  six-digit code and where the sign-in returns to. Approve only when the code
  matches the one on your own sign-in page. Anyone who knows your public
  address can ask to connect under any name.
- **Sign-in requests are limited and expire.** A request expires after 5
  minutes. One app can have 2 waiting, and all apps 16.
- **Tool calls waiting for you are limited.** A call waits 90 seconds. One app
  can have 4 waiting, and all apps 16. When an app disconnects, its waiting
  request is withdrawn.
- **The Requests menu shortcuts act only on the request you can see** in the
  Approval window.
- **Tools changed outside MacRemote start Not Shared.** If the saved tools file
  is edited by hand or by another program, the changed tools are Not Shared
  until you review them, and Activity lists them.
- **Scan This Mac no longer starts other apps' MCP servers.** A server starts
  only when you import or check it. If a server relabels a shared tool that
  asked first as read-only, the tool becomes Not Shared until you review it.
- **Full Disk Access needs only MacRemote.** MacRemote no longer asks you to add
  tools or script interpreters. If you added Python, Node, a shell, or a tool
  to Full Disk Access because MacRemote listed it, you can remove it.
- **One sign-in method at a time.** Changing the sign-in method signs out
  every app that connected another way, and Settings says what was removed.
  Client IDs and secrets you created work only under OAuth Client Secret.
  Nothing changes for your connected apps until you change the method.
- **A copied sign-in is caught.** Each time an app renews its sign-in it gets
  a new renewal token and the old one stops working. If an old one is used
  again more than a minute later, someone else holds a copy, so MacRemote ends
  that sign-in and says so in Activity. The app signs in again.
- **Apps you never approved leave nothing behind.** An app you deny, or whose
  request expires, is forgotten and never saved. It may need to be added again
  in that app before it can ask a second time.
- **Public requests are limited per caller,** so one stranger cannot lock your
  apps out of signing in.
- **Download links are built only for the built-in File Transfer tools.**
- **The public link stops whenever MacRemote does.** Quitting stops it. So does
  a crash or a Force Quit: the Cloudflare helper stops at once.

### Fixed

- **The Tools page fits a narrow window.** With the inspector open, the filter
  chips now wrap onto more lines instead of breaking their labels apart, and
  a tool row keeps the tool's name readable before its chips.
- With **Your Domain** chosen, **Go Public** started a random Instant Link. It
  now brings your deployed domain back, or opens the Address card when nothing
  is deployed yet.
- The public link showed as running while it had no connection to Cloudflare:
  briefly when an Instant Link started, and for as long as the network was down
  or after the Mac woke. It now shows Reconnecting until the link is back.
- **Load Domains** showed only the first 50 domains of a Cloudflare account.
- A subdomain with accented or other non-ASCII characters, or a hostname longer
  than 253 characters, was accepted.
- A tool that timed out or was cancelled could leave behind programs it had
  started. MacRemote now stops everything the tool started.
- A tool stopped at its time limit was now and then reported as having failed,
  not as having timed out.
- A few slow tools or stuck local MCP servers could make MacRemote stop
  answering every app.
- A remote MCP server that answered slowly without finishing could keep a call
  open far past the tool's timeout. The call now ends at the timeout, and a
  response over 32 MB is refused.
- A local MCP server that stopped reading its input could keep a call open
  without end.
- **Scan This Mac** could keep running when a server never finished answering.
- Signing in to an MCP server never timed out if you closed the browser tab,
  and MacRemote then refused every sign-in until you relaunched it. A sign-in
  now ends after 5 minutes.
- Two calls made as a sign-in expired, or a brief server or network problem,
  could sign you out of an MCP server.
- Tools now get your user name and a temporary folder of their own. Python and
  other tools no longer fall back to the shared `/tmp`.
- A large download could use more than twice its size in memory. Downloads are
  now sent in small pieces.
- Files staged for download could stay in the temporary folder after a crash.
  MacRemote clears them at launch and deletes each one when it expires.
- Download Zip refused the top of the disk as its base folder.
- Zip downloads no longer contain a `__MACOSX` folder.
- A file tool pointed at a stalled network volume held its call open. It now
  ends at the tool's timeout.
- A failed Instant Link could show an address that was not this Mac's and
  restart the helper without end.
- A Cloudflare helper installed by an earlier beta keeps working after you
  update the app. Settings offers the newer helper.
- Two malformed requests could end MacRemote. Both are now rejected.
- An imported MCP server that exited during a call could end MacRemote.
- A tool that left a background process running kept its call open until that
  process ended.
- Write File said it accepted 10 MB per call. One call carries 96 KiB; an app
  sends a larger file in parts.
- macOS could refuse Reminders access without showing its prompt, which
  blocked the server from starting.
- A sign-in request nobody answered stayed in the Approval window, the Dock
  badge, and the menu bar count after it expired.
- The sentence under a sign-in request said every Asks First tool would ask,
  even when the app already had Always Allow rules. It now counts them.
- **Allow All Current Tools** granted tools that were not shared.
- **Update from Catalog** refreshed only one of the RemCTL and NotesCTL servers.
- **Reset Private Address** said the public link stays the same. An Instant
  Link gets a new address the next time you go public.
- Menus and notifications could open extra main windows.
- On Intel Macs, tools installed with Homebrew lost their package details.

## What 1.0 does not claim

MacRemote is a hand-written Swift MCP implementation. This release does not
claim complete MCP or OAuth conformance, or publication in the ChatGPT or
Claude app directories.
