# MacRemote 1.0

MacRemote is a Mac app that lets ChatGPT, Claude, and other AI apps use the
tools you choose on your Mac, from any device. AI apps call outside tools
through MCP, the Model Context Protocol. MacRemote runs an MCP server on your
Mac, gives it a public HTTPS address through Cloudflare, and decides, with
you, what every app may see and run.

It is free and open source under the MIT License.

## Download

Download `MacRemote-1.0-macos-universal2.zip` from
[GitHub Releases](https://github.com/viticci/MacRemote/releases). Unzip it,
move **MacRemote** to Applications, and open it. The release also lists a
`.sha256` checksum for the ZIP.

[Install MacRemote](../../INSTALL.md) walks you through the first run, from the
download to your first tool call.

## Requirements

- macOS 26 or later, on an Apple silicon or Intel Mac. The app is universal.
- An AI app that can connect to a remote MCP server, such as ChatGPT or Claude.
  An app on the same Mac can use the local address instead.
- For a stable address only: a Cloudflare account, a domain in it, and either
  Wrangler's sign-in or an API token. Instant Link needs none of these.

MacRemote is signed with a Developer ID and notarized by Apple, so it opens with
a double-click. You do not need Xcode, Homebrew, or a terminal.

## If you used an earlier build

If you ran MacRemote before 1.0, your saved tools, their **Share** settings,
your connected apps, and your settings carry over. One thing changes. Some
Flexible Commands saved from an earlier build had built-in limits on the
arguments they accepted. 1.0 removes those limits, so the first time it opens,
MacRemote clears any **Always Allow** grant those tools had, and **Activity**
names them. They ask on every call until you choose **Always Allow** again for
an app you trust.

## What MacRemote does

### Shares the tools you choose

- Add a command-line app, a single workflow from one, or a whole bundle from
  the **Library**. Apps see tools whose **Share** switch is on.
- Every tool runs as one exact program with an exact list of arguments. There
  is no shell: no pipes, wildcards, or `~` expansion, and shells like `bash`
  and `zsh` can't be added as tools.
- Each tool is labeled **Read-only**, **Write**, or **Destructive**. Read-only
  tools run without asking; the others ask first.
- A **Fixed Command** runs a set workflow with checked inputs. A **Flexible
  Command** passes any arguments to its program, so it always asks first.
- **Welcome** gets a new Mac to a first tool call: pick a tool such as the
  built-in **Current Date**, grant any macOS permissions it needs, and go
  public.

### Approves every app and every risky call

- A new app's sign-in page and MacRemote both show a six-digit code. Approve
  only when they match; anyone who knows your address can ask to connect under
  any name.
- A tool that can change something asks first in a floating Approval window,
  and shows every argument in full, invisible characters included. A call is
  checked before you are asked, so a bad one fails without a prompt.
- **Always Allow** works for one app and one tool. Changing what the tool runs
  makes it ask again.
- Notification banners can deny a request but never approve one.
- Sign out one app or all of them from **Apps** and **Settings → Security**.
- Sign-in uses **Dynamic OAuth** by default: the app registers itself and you
  approve it on the Mac. **OAuth Client Secret** and **Single Header** are
  there for apps that can't do that.

### Goes public with Instant Link or Your Domain

- **Instant Link** gives you a temporary `trycloudflare.com` address with no
  account.
- **Your Domain** gives you a stable address on a domain you own through
  Cloudflare. After the first deploy, **Go Public** brings it back, also after
  a restart, without your API token. The token is never saved.
- MacRemote downloads and checks its own copy of Cloudflare's helper, or uses
  one you installed.
- For a Mac that stays on, **Open at login** and **Go public at launch** bring
  Your Domain back after a restart. A restart or shutdown never waits on
  MacRemote's quit dialog.
- MacRemote's server listens only on your Mac. Cloudflare carries requests to
  it, but MacRemote checks every sign-in itself, and it answers only at its own
  local address and its own public link. Quitting MacRemote always stops the
  public link, even after a crash.

### Moves files, inside the folders you allow

- Ten built-in **File Transfer** tools can look up, list, find, read, write,
  append to, edit, receive, and download files.
- They reach Desktop, Documents, and Downloads until you add folders in
  **Settings → Security → File Transfer Folders**. **Allow Whole Mac…** opens
  every file your account can read, for apps you trust.
- Protected locations, such as SSH and GnuPG keys, cloud credentials,
  Keychains, and MacRemote's own data, are never reachable, even with the whole
  Mac allowed.
- **Append to File** and **Replace in File** change a text file without sending
  it again. **Upload File** receives a whole file, up to 512 MiB, from apps that
  support MCP file uploads. **Download File** and **Download Zip** return a
  short-lived link, good for up to three downloads, instead of the file's
  contents.
- Every tool that writes asks first. Tools that run without asking can only be
  pointed at files in the same folders.

### Brings your MCP servers and Federico's CLIs along

- The **Local MCP Bridge** imports tools from MCP servers you already set up for
  Claude Desktop, Claude Code, Codex, Cursor, VS Code, and other apps, and
  shares them from one place. A scan never starts another app's server.
- When a bridged server needs to ask you something mid-call, the question
  reaches the app you are using, in apps that support MCP questions.
- If you use RemCTL, NotesCTL, MailCTL, PhotoCTL, MusicCTL, or Apple Frames,
  MacRemote finds them under **Tools → Federico Viticci**. The ones with their
  own MCP server keep their tools in step with the installed version: after an
  update, MacRemote reads the tool list again and **Activity** says what
  changed. All of them are optional.

### Keeps long calls working

- In apps that support MCP Tasks, such as Claude and Claude Code, a call still
  running after 20 seconds continues in the background, so it does not hit the
  public link's time limit. The app picks up the result when it finishes.
- Turn on **Long-Running** for a tool you know takes a while, and it starts in
  the background right away.

### Gives apps a guide to your tools

- Apps that support MCP skills, such as Claude Code, get **macremote**, a short
  guide to how MacRemote's tools, approvals, and download links work.
- MacRemote can also share skills from servers you imported and skills already
  on your Mac for the tools you use. Each one starts Not Shared, because a
  skill's text becomes instructions for the assistant.

### Shows results as cards, if you want

- Apps that support MCP Apps, such as Claude and ChatGPT, can show results as
  cards that follow the app's light or dark theme. Cards are off until you turn
  on **Show result cards** in **Settings › General**, and each tool family has
  its own switch.
- A card only formats the result. Every app gets the same result as text and
  structured data: the tool's output, within MacRemote's size limits, and a
  reason code. Output too large to fit arrives as a short-lived download link.

## Known limits

- **Some new tools start Shared.** Tools you make yourself, and Fixed Command
  presets from the Library, start Shared, even while an app is connected.
  Library Flexible Commands, scan results, File Transfer, and tools a CLI adds
  in an update start Not Shared. [Share more
  tools](../../INSTALL.md#6-share-more-tools) has the full list. Review
  **Share** in **Tools** before you connect an app.
- **Keep MacRemote open.** The local server and the public link stop when it
  quits. An Instant Link gets a new address each time you start one, so update
  it in your app.
- **Claude does not send files to MacRemote yet.** Claude sends files only to
  connectors in its Connectors Directory, and each MacRemote has its own
  address. Upload File works with other apps that support MCP file uploads;
  apps without them use Write File, which sends a file in small parts.
- **Some features use parts of MCP that are still drafts or new.** MCP file
  uploads are a draft extension. Background tasks, skills, and questions from
  bridged servers work only in apps that support them. All of these may change
  as MCP does.
- **Apps without MCP Tasks** must get a result before the public link or the
  app stops waiting. Cloudflare's current default is 125 seconds, and an app
  may give up sooner. Background tasks end when MacRemote quits or
  stops sharing; a finished result stays available for one hour.
- **Large uploads over the public link** can be refused by Cloudflare's own
  request limit (100 MB on its free plan).
- **Go public at launch** works only with a deployed Your Domain, and only once
  someone logs in to the Mac, or automatic login is on.
- **ChatGPT's setup has not been tested live in its current form.** ChatGPT
  now adds custom MCP servers from its Plugins page, on some plans only.
  [Connect ChatGPT](../CHATGPT.md) has the steps and lists what is unchecked.
- **The icon an app shows is up to the app.** ChatGPT shows one only if you
  upload it. Claude shows the website icon of your link's main domain.
- **Single Header** sign-in has no connection approval; tool approvals still
  apply. ChatGPT, Claude, and Notion can't use it.
- **No directory listing.** MacRemote is not listed in the ChatGPT or Claude
  app directories, and it has not been submitted as an OpenAI plugin. It is a
  hand-written Swift MCP server and does not claim complete MCP or OAuth
  conformance.
