# MacRemote 1.1

MacRemote 1.1 adds a menu bar mode and fixes two problems with command-line
tools found by a scan, both reported on GitHub. Your tools, settings, and
connected apps carry over from 1.0.

## Download

Download `MacRemote-1.1-macos-universal2.zip` from
[GitHub Releases](https://github.com/viticci/MacRemote/releases). Unzip it,
move **MacRemote** to Applications, and open it. The release also lists a
`.sha256` checksum for the ZIP. MacRemote is signed with a Developer ID and
notarized by Apple.

## New

- **Run MacRemote from the menu bar**
  ([#10](https://github.com/viticci/MacRemote/issues/10)). Turn off **Show
  Dock icon** in **Settings › General ▸ App Behavior**, and MacRemote leaves the
  Dock and Command-Tab. The menu bar icon stays on while the Dock icon is
  hidden, and its menu gains **Settings…**. Removing the menu bar icon by
  Command-dragging it brings the Dock icon back.

## Fixed

- **False "changed publisher" warning on Homebrew apps**
  ([#7](https://github.com/viticci/MacRemote/issues/7)). Homebrew starts apps
  such as VLC and Blender through a two-line launcher script. When you added
  one of these tools, MacRemote recorded the app's signature, but every later
  check read the unsigned script, so the tool was flagged and its sharing
  turned off the first time it ran or was shared. MacRemote now checks the app
  both times. A real publisher change is still caught.
- **Review… did nothing.** The warning's **Review…** button now opens the
  inspector to the warning, with who signed the tool when you added it and who
  signs it now, and a **Trust New Publisher** button. Trusting accepts the
  change: Always Allow no longer applies to the tool, and it stays Not Shared
  until you share it.
- **Apps you have used for years showed as Quarantined**
  ([#8](https://github.com/viticci/MacRemote/issues/8)). macOS keeps the
  quarantine mark on a downloaded app after you open it, and records your
  approval in it. MacRemote now labels a tool **Quarantined** only when macOS
  has not approved it yet.
- **The Quarantined label stuck after Scan Again.** When no folder had changed,
  Scan Again reused its saved results, including the old label. It now reads
  the quarantine mark again on every scan.

## If a tool was flagged in 1.0

1.0 turned off sharing for a Homebrew tool it flagged by mistake, and 1.1
does not turn it back on for you. Turn the tool's **Share** switch back on if
you want apps to use it again.
